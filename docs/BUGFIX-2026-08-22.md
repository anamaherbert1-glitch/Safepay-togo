# SafePay V5 bug-fix scope — 2026-08-22

This change set targets the deployed V5 authentication and mobile UI issues reported during verification:

- Google OAuth provider error handling and redirect flow.
- Password visibility controls.
- Success/info messages no longer styled as errors.
- Email verification returns to SafePay through the existing callback route.
- Registration remains blocked until email, phone OTP and profile are complete.
- Login remains phone + OTP only.
- Profile navigation remains a single bottom-navigation entry and avatar replaces the vector icon.
- Mobile layout/loading stability and button visual consistency are preserved.

External Supabase configuration is still required for Google OAuth, phone SMS/OTP and the production Site URL / redirect allow-list. These cannot be safely changed through application source code alone.
